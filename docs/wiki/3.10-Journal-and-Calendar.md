# Journal and Calendar

Open **Journal** in the sidebar and choose a date or a daily, weekly or monthly view.

## Record activities

The daily calendar uses 15-minute slots. Click a slot to open the activity editor or drag across slots to select a longer range. Enter a name, category and optional note, then save. Start/end times can also be entered manually; new intervals use quarter-hours and the end can be `24:00`.

Click an activity to edit it. Drag its body to move it while preserving duration, or drag either edge to resize. Changes stay within the day. If a manual change overlaps another entry of the same type, it is rejected and the original record remains. Native task schedules that already overlap appear side by side. **Plan vs actual** displays separate lanes; planned time does not count as actual recorded time. **List** provides edit/delete controls.

On touch screens, tap to record and swipe empty slots to scroll. Keyboard users can activate a slot or activity with Enter and use Up/Down to move a focused activity or resize a focused edge. Escape cancels a selection or closes the editor.

## Common activities

**Customize** lets you add, rename or delete common activity templates. Only the shortcut's template name is required; activity name, category, plan/actual type, start, end, duration, linked task and multiline note are optional. Blank fields keep the current activity values. A blank activity name uses the current name, or the template name if the activity has no name yet. **Keep current value** preserves an existing task link; **No linked task** explicitly clears it for a new/manual activity. Editing an existing linked native plan always keeps its original task. Deleting a shortcut keeps past records. An empty saved list stays empty.

Choose a shortcut in the activity editor to fill its details. Fixed template start/end times override the selected range, with an explicit end taking priority over duration. Without fixed times, a dragged range longer than one slot keeps its duration. A clicked slot or panel shortcut uses a provided duration, capped at midnight; omitting all time fields keeps the current range. Times and durations use 15-minute steps; an end can be `24:00`. Review the times before saving.

**Save as common template** copies every field of the current activity editor into a new reusable template. This saves the shortcut only; the activity still needs its own **Save**. Templates do not start timers or create/change tasks until you save an actual activity or linked plan. If a preset's linked task is unavailable, the editor asks you to choose another task instead of applying that template.

## Tasks and reviews

Select a **Linked task** to reuse an existing task. Linked plans edit the original task's name, notes, estimate and scheduled time. Changes made through the original task interface appear on the calendar automatically. Tasks scheduled with a start time appear in the plan lane; date-only tasks appear in the task overview without an invented start time.

**Create task** converts a manual plan into an original timed task. **Cancel schedule** clears its calendar placement and keeps the task. **Record as actual** opens a separate manual record for review and saving. Completing a task does not automatically claim that its planned time interval occurred.

The task overview shows scheduled tasks, tasks completed in the period and recorded task time, including loaded archived history. Its checkboxes and play/pause controls use the original task system. Accumulated timer duration is shown separately from manual activity duration to avoid double counting; it cannot reconstruct exact historical execution intervals.

The daily page embeds the original reflection editor, so it and the daily summary edit the same reflection. Longer journal text remains separate in daily notes. Weekly/monthly views and Markdown exports include daily notes, reflections, activities and task information. Automatic views never overwrite personal journal text.

## Data compatibility

Common activities use an optional miscellaneous configuration field. Native task schedules remain on the original task, with an optional journal category. No new plugin API, entity type, operation type or schema migration is introduced. Existing clients can ignore the optional fields. Backups include these fields through existing task, metric and configuration storage. Daily activity lists retain the original metric conflict policy; concurrent edits are not merged per activity.
