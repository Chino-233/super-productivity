# 设置与偏好

设置界面是所有可用选项及其默认值的权威来源。本页介绍一些无法从标签直接看出的行为，并非逐项抄录全部设置。平台差异请参见 [3.05-Web-App-vs-Desktop](../../wiki/3.05-Web-App-vs-Desktop.md)。

## 全局设置

设置标签页上方有一个搜索框。输入内容后，会同时搜索所有标签页，并在下拉列表中显示匹配项，包括所属分区，以及（如果匹配到具体选项）该选项的标签。选择结果后会切换到相应标签页、展开分区并滚动到该选项。搜索标签页名称会列出该标签页上的所有内容。无法折叠成分区的设置也可以搜索，包括外观组（深色模式、主题和壁纸）、声音、插件和同步设置。

### 应用功能

- **全新安装时的默认功能** — 全新安装会默认启用时间追踪、规划器、项目笔记、搜索、同步按钮和“支持我们”页面。日程、日程日期面板、看板、习惯、问题面板、“结束一天”和专注模式默认关闭，可以在此处开启。已有数据会保留自己的设置。默认值本身永远不会被保存或同步；在此处更改某个开关时，只会同步该开关，因此新设备不会关闭其他设备上的功能。如果某个账号从未更改过功能设置，新设备加入后可能会显示较少功能，直到你在新设备上将其开启。
- **在功能出现的位置关闭它** — 规划器、日程、看板和习惯的侧边栏菜单中都有**禁用功能**选项；如果有正在追踪的任务，也可以右键点击顶部栏中的播放按钮（触摸设备上长按），以关闭时间追踪。

### 本地化

- **语言** — 打开全局“设置”界面，选择“常规”，然后展开“本地化”。选择“简体中文”即可使用中文界面。项目或标签菜单中的“设置”对话框配置的是对应项目或标签，不包含应用语言选项。更改语言后，页面标题会立即更新；用户自行创建的名称会保留。
- **日期时间格式地区** — 控制应用_显示_的数字日期格式和时间的 12/24 小时制。ISO 8601 选项使用 `YYYY-MM-DD` 格式和 24 小时制。选择 ISO 8601 后，“日程”“习惯”和“规划器”中的星期标签会遵循应用语言。“系统默认”选项遵循浏览器或操作系统的地区设置；如果系统没有该地区的格式化数据，日期会回退到英式英语（en-GB）格式。

  此选项不会影响**时间输入框**——日程和截止日期对话框中的时间输入使用浏览器原生控件，浏览器会按照浏览器或操作系统界面的语言显示时间格式，网页无法覆盖该设置。因此，即使此处选择了 24 小时制地区，在采用 12 小时制的系统上，时间输入框仍会显示 `02:00 PM`；保存的时间依然正确。

### 其他设置

- **在系统托盘/状态菜单中显示当前倒计时（仅 macOS）** — 在桌面端状态菜单标题中显示正在运行的计时器或倒计时。关闭此选项且启用了当前任务显示时，标题可以改为显示当前任务。
- **自动检查新版本（仅桌面端，默认开启）** — 桌面应用每天会查询一次 GitHub Releases API，检查是否发布了新版本，并显示可关闭的通知，其中包含下载页面链接。不会发送个人数据，也不会自动安装任何内容，并且每个版本最多通知一次。没有自己的更新渠道的构建版本才会显示此设置（以及设置页脚中的手动“检查更新”链接）；Microsoft Store、Mac App Store 和 Snap 版本通过各自商店更新，不会执行此检查。
- **在每日总结中关闭庆祝动画（默认开启）** — 关闭每日总结和项目完成时显示的纸屑动画。取消勾选即可启用庆祝效果。在默认值更改前保存过此设置的安装版本会保留之前的选择。
- **启用本地 REST API（仅桌面端，默认关闭）** — 在 `http://127.0.0.1:3876` 上启动一个 localhost HTTP API，供本地脚本和工具调用。除 `GET /health` 外，每个请求都必须在 `Authorization: Bearer <token>` 中提供生成的访问令牌。令牌会显示在此设置下方，并且可以重新生成；重新生成后旧令牌会立即失效。这项更改会破坏使用无身份验证 API 的旧版客户端。

### 任务

- **在系统托盘/状态菜单中显示当前任务（仅 macOS/Windows）** — 允许桌面端系统托盘或状态菜单显示当前活动任务。在 macOS 上，启用当前倒计时设置时，倒计时会优先显示。
- **在任务备注中启用 Markdown 格式（默认开启）** — 编辑备注时会使用支持边输入边渲染 Markdown 的编辑器，只在当前编辑行显示纯语法。关闭后，所有编辑备注的位置（任务备注、项目备注和全屏编辑器）都会改用纯文本框；备注内容本身不会改变。
- **优先级图标（默认：尖括号）** — 设置任务标题旁边和优先级菜单中显示优先级的方式：尖括号或带圆圈的数字（3 = 高、2 = 中、1 = 低）。每个选项都会预览对应图标。未设置优先级的任务不会显示图标。

### 简写语法

- **启用截止日期简写语法** — 输入任务标题时解析 `!<截止时间>`。此选项默认关闭。

### 闲置时间处理

- **启用闲置时间追踪** — 启用后，Super Productivity 会检测你离开电脑的情况，并显示闲置对话框询问你期间做了什么。
- **最短闲置时间** — 你需要离开多久才会显示闲置对话框。必须至少为 **1 分钟**：桌面应用不会报告更短的闲置时间，因此低于该值时会向上取整到约一分钟，而不会遵循较短设置。闲置状态每 30 秒采样一次，因此达到阈值后，对话框最多可能再延迟 30 秒出现。
- **仅在有活动任务时显示闲置对话框** — 只有当前正在追踪任务时才显示闲置对话框。
- **工作时段内不显示闲置对话框** — 启用后，专注模式的工作时段运行期间不会显示闲置对话框。如果你在电脑前工作但没有键盘/鼠标操作（例如阅读、学习或参加考试），此选项会很有用。默认关闭（需自行启用）。

## 同步与导出

### 自动备份

- **启用自动备份** — 在当前平台支持时自动创建本地备份。
- **恢复最新的自动备份** — 仅 Android。恢复最新的可用自动备份；确认后会替换当前本地数据。
- **最多保留的备份文件数** — 仅桌面端。限制 `backups/` 文件夹中自动备份 JSON 文件的数量；超过限制后会删除较旧的文件。

## 项目、标签、今天和收件箱设置

### 基本设置

- **启用项目待办列表** — 为项目添加单独的待办列表。
- **在侧边栏隐藏项目** — 从侧边栏项目列表中移除该项目。项目仍处于活动状态：其任务仍可显示在跨项目视图中，例如“今天”、规划器、日程、看板和搜索。要重新显示项目，请使用侧边栏可见性菜单；项目简写语法不会匹配已隐藏的项目。

### 主题

主题设置可以为浅色模式、深色模式或两者设置背景图片。至少设置一张背景图片后，才会显示背景对比度和模糊度滑块。模糊度滑块默认值为 `0px`。如果至少有一种模式没有背景图片，则会显示有色背景色调设置。主题详情请参见 [3.09-Theming](../../wiki/3.09-Theming.md)。
