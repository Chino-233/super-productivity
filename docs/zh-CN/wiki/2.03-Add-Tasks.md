# 添加任务

本操作指南介绍如何向列表中添加新任务。关于子任务、安排日程、重复任务和关联问题的任务，请参见 [2.04-Manage-Subtasks](../../wiki/2.04-Manage-Subtasks.md)、[管理已安排的任务](2.05-Manage-Scheduled-Tasks.md)、[2.06-Manage-Repeating-Tasks](../../wiki/2.06-Manage-Repeating-Tasks.md) 和 [2.07-Manage-Task-Integrations](../../wiki/2.07-Manage-Task-Integrations.md)。

## 打开“添加任务”栏

**通过顶部栏：** 点击顶部栏中的**添加新任务**按钮（加号图标）。添加任务栏会展开，光标自动定位到输入框。

**使用键盘：** 按 **Shift+A**（“添加新任务”的默认快捷键）。你可以在 [设置与偏好](3.02-Settings-and-Preferences.md) →“键盘”中查看或更改快捷键；另请参见 [3.03-Keyboard-Shortcuts](../../wiki/3.03-Keyboard-Shortcuts.md)。

## 创建任务

1. 打开添加任务栏后，在输入框中输入任务标题。占位文字会显示示例：**任务标题 #标签 @16:00 t25m**（标题中可以使用 **#标签**、**@时间**、**@日期** 和 **[t]时间**；详见下文）。
2. 按 **Enter** 或点击输入框旁边的**添加任务**按钮（加号图标）。任务会添加到当前项目或上下文（今天/标签）中。

> 你也可以将 `.eml` 邮件文件拖放到**添加任务**按钮（顶部栏中的 **+** 图标）上来创建任务。任务标题会采用 `发件人: 主题` 的格式。邮件的纯文本部分（包括 quoted-printable/base64 编码正文，以及带有 HTML 替代内容的多部分邮件）会作为纯文本保存到任务备注中；只有 HTML 正文的邮件和不支持的编码只会创建标题任务。

新任务会根据添加栏设置出现在列表的**顶部**或**底部**（见下文“添加到顶部或底部”）。

## 标题中的简写语法

输入标题时可以使用：

- **#标签名** — 将任务添加到标签中（例如 `#work`）。如果标签不存在，可以在添加任务时创建。
- **@16:00** 或 **@09:30** — 设置任务的到期时间（只提供时间时默认为今天）。
- **@明天**、**@下周** 或某个日期 — 设置到期日期。也可以与时间组合使用（例如 **@明天 @14:00**）。
- **!星期五**、**!下个月** 或 **!14:30** — 在设置中启用截止日期简写语法后，设置截止日期/时间（默认关闭）。
- **[t]25m** — 设置任务的预估用时。也可以在末尾添加 `/`，同时记录任务之前花费的时间（例如 `t30m/`）。`t` 标记可以省略，即使不写也能使用简写语法。

参见 [3.04-Short-Syntax](../../wiki/3.04-Short-Syntax.md)，了解可用简写标记的更多信息。你也可以从帮助菜单重新启动交互式的**如何创建任务**导览。

添加任务栏还提供操作按钮，无需输入文字即可设置属性：

| 按钮 | 快捷键 | 说明 |
| ------------ | -------- | --------------------------- |
| **安排日程** | `Ctrl+4` | 设置到期日期/时间 |
| **标签** | `Ctrl+5` | 分配标签 |
| **预估** | `Ctrl+6` | 设置用时预估 |
| **重复** | `Ctrl+7` | 配置重复日程 |

此外，按 **Ctrl+8** 可直接打开截止日期对话框；如果标题中已解析出截止日期，也可以点击对应的截止日期标记。

设置值后，对应的操作按钮或标记旁会出现 **×** 清除按钮。在“日程”或“规划器”视图中，添加栏可能会显示不同选项（例如“安排在今天”）。

### 截止日期与日程安排

- **安排日程**（`Ctrl+4`）：_计划何时处理任务_——将任务安排到每日计划中。
- **截止日期**（`Ctrl+8`）：_任务最晚必须完成的时间_——这是硬性截止时间。截止日期为今天的任务会自动移入“今天”列表。

## 添加到顶部或底部

输入框旁边的按钮可以切换新任务添加到列表的**顶部**还是**底部**。悬停提示会显示“添加到顶部（Ctrl+1）”或“添加到底部（Ctrl+1）”。你也可以按 **Ctrl+1**（或自己设置的快捷键）进行切换。此设置只对下一个添加的任务生效。

## 添加到待办列表或今天（项目启用了待办列表时）

如果当前项目启用了**待办列表**，还会显示另一个按钮：**添加到待办列表** / **添加到今天**。它可以切换新任务是添加到项目的**待办列表**还是**今天的列表**。图标和悬停提示（“添加到待办列表”或“添加到今天”）会显示当前模式。

## 添加已有任务或问题（搜索模式）

点击添加任务栏中的**搜索**图标（或按 **Ctrl+2**，如果已配置）可切换到**问题搜索**模式。占位文字会变为“添加已有任务或问题……”。你可以搜索：

- **归档中的任务**或其他项目中的任务——选择一项，将其添加到当前上下文。
- 已配置集成中的**问题**（Jira、GitHub 等）——选择一项，将其作为关联任务添加。

输入文字进行搜索，然后从列表中选择要添加的条目。再次点击搜索按钮或按 **Ctrl+2** 可关闭搜索，返回普通的“创建新任务”模式。

## 新任务会添加到哪里

- **项目视图：** 任务会添加到**当前项目**。启用“添加到待办列表”后，任务会进入项目待办列表；否则会进入主列表（或根据上下文进入今天列表）。
- **今天/标签视图：** 任务会添加到**当前标签**（例如“今天”）。任务也会归属某个项目；如果你当前正在项目的“今天”视图中，任务就属于该项目。
- **日程/规划器：** 在这里使用添加栏时，可以为特定日期（例如今天）安排任务；新任务会被安排到该日期。

## 从日程/规划器添加任务

在“日程”或每日规划视图中，某一天旁边可能会有一个**添加**按钮（加号图标和“添加”字样）。点击后会在原位置打开同一个添加任务栏；你可以创建任务并将其安排到该日期。创建任务后，内嵌添加栏会关闭。

## 一次编辑多个任务

选中多个任务后，可以对所有任务应用同一项更改。选择是临时的：切换项目或标签、离开当前视图或按 `Escape` 时，选择会清除。

### 选择任务

- 按住 Ctrl 点击任务（macOS 上按住 Cmd）可将其加入选择；再次点击可取消选择。
- 按住 Shift 点击任务，可选中上次切换选择的任务与当前点击任务之间的所有任务；如果尚未选中任何任务，则从当前聚焦的任务开始选择。
- 聚焦某个任务后，可按 `Shift`+`ArrowDown` / `Shift`+`ArrowUp` 使用键盘扩展选择范围；按 `X` 切换当前聚焦任务的选择状态；按 `Ctrl`+`A` 选择整个列表。
- 普通点击某个任务会只选中该任务，并清除其他选择。
- 在触摸屏上，向左滑动任务以打开菜单，然后选择**选择多个任务……**。随后每个任务会显示圆环而不是完成框；点击任务即可选中或取消选中。应用操作、取消最后一项选择，或使用工具栏中的 ✕、返回按钮或 `Escape`，都会退出选择模式。选择期间会暂停滑动、拖动和标题编辑。

选中的任务会显示带色调的背景，左侧有一条强调色条。这里特意不显示勾选标记：勾选标记表示_已完成_。

### 对选中任务执行操作

列表底部会出现一个工具栏，显示选中的任务数量。点击**操作**可打开菜单，选择要批量应用的操作：安排日程、取消日程、添加到今天、设置截止日期、标记为完成或未完成、移入待办列表或移回、预估用时、管理标签、移至其他项目、删除。右键点击任意已选任务或按 `Q`，也会打开相同菜单。选择生效期间，常用任务快捷键（`D`、`Backspace`、`S`、`Shift`+`S`、`Shift`+`T`、`U`、`Shift`+`B`）会作用于整个选择。

以下规则有助于让批量编辑更可预测：

- 完成状态会逐一应用到每个选中任务；将父任务标记为完成不会自动完成其子任务。
- 移动到项目或待办列表的操作只适用于顶层任务；选中的子任务会跟随父任务移动，并标记为已跳过。
- 移动重复任务时，每种重复配置只会询问一次，并将配置连同所有实例一起移动，行为与移动单个任务相同。
- 删除多个任务时总会要求确认，因为目前批量删除无法撤销。只选中一个任务时，删除行为与普通删除相同，会遵循确认设置并提供撤销功能。
- 标签：如果所有选中任务都已有该标签，就从所有任务中移除；否则将其添加到所有任务。
