## 语言和更新

应用语言在侧边栏 **设置 → 常规 → 本地化 → 语言** 中选择 **简体中文**。项目或标签自己的“设置”弹窗没有全局语言选项。

本批中文译文由 Luna 子代理翻译，共 13 篇。尚未翻译的开发与参考文档保留英文，相关链接会跳转到英文原文。

英文文档以 `master` 为准；本分支保留 `README.en.md`、`CONTRIBUTING.en.md` 和 `docs/wiki/` 原文。译文源版本记录在 [translations.json](translations.json) 中。维护方式见[英文与中文同步说明](MAINTENANCE.md)。
